# Formative 1, Part 2 — Classical ML Classification Challenge

## About the competition

This is a Kaggle InClass binary classification challenge run for our course cohort, built on a synthetic dataset (37 numeric features, 3 categorical features, ~30,000 training rows). The task is to predict `target`, a binary outcome with a roughly 26% positive rate, and models are scored by ROC-AUC — a threshold-independent metric well suited to the class imbalance here. The goal of the assignment was to build and systematically tune classical machine learning classifiers, tracking every experiment through Weights & Biases, and to compare model families against a logistic regression baseline.
